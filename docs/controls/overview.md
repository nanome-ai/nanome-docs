# Nanome Controls

## In-VR Controls

<ShotRow src="controls-page/2_Grip.png" alt="Side view of a controller, with the trigger at the front and the grip below it" crop="4.0,12.6,43.0,83.5">

**Trigger and grip**

<UiList label="Trigger and grip">
<UiItem name="Trigger" area="39.1,21.7,6.0,18.8">Press to interact with the menu buttons and interfaces your laser is pointed at.</UiItem>
<UiItem name="Grip" area="15.5,45.7,14.4,14.1">Press and hold. Grab objects with both grips to scale.</UiItem>
</UiList>

</ShotRow>

<ShotRow src="controls-page/3_RTB.png" alt="The right controller seen from above, with its top button and joystick" crop="6.9,7.1,36.7,84.6">

**Right controller**

<UiList label="Right controller">
<UiItem name="Right Top Button" area="16.7,19.1,7.2,9.3">Press and hold to open the tools menu. Release on the desired tool.</UiItem>
<UiItem name="Right Joystick" area="26.7,23.3,8.7,11.6">Move left/right when using any tool to switch to the next tool. Move up/down when grabbing an object to push/pull the object.</UiItem>
</UiList>

</ShotRow>

<ShotRow src="controls-page/6_MenuButton.png" alt="The left controller seen from above, with its top button, joystick and menu button" crop="6.9,7.1,36.7,84.6">

**Left controller**

<UiList label="Left controller">
<UiItem name="Left Top Button" area="26.9,19.9,7.2,9.5">Press to open and close the action menu, which allows quick access to tools.</UiItem>
<UiItem name="Left Joystick" area="15.0,23.3,8.6,11.6">Move left/right when using the Medchem tool to switch the Medchem tab. Move up/down when grabbing an object to push/pull the object.</UiItem>
<UiItem name="Menu Button" area="19.5,37.4,4.7,6.1">Press to open the settings/help menu.</UiItem>
</UiList>

</ShotRow>

## 2D Controller Bindings

<ShotRow src="controls-page/2D_Controller.png" alt="A gamepad with the Nanome bindings for each button">

**Joystick**

<UiList label="Joystick">
<UiItem name="Left stick" area="35.9,35.7,4.7,9.9">Modifier: while clicked, rotate axes is MAX.</UiItem>
<UiItem name="L3" area="35.9,35.7,4.7,9.9">Modifier: while clicked, move axes is MAX.</UiItem>
<UiItem name="Right stick" area="49.6,46.7,4.9,10.1">Set move axes to low preset.</UiItem>
<UiItem name="R3" area="49.6,46.7,4.9,10.1">Modifier: while clicked, rotate axes is MAX.</UiItem>
</UiList>

**D-Pad**

<UiList label="D-Pad">
<UiItem name="Up" area="41.6,47.1,2.1,3.8">Divide move values by 2.</UiItem>
<UiItem name="Down" area="41.6,54.7,2.1,3.4">Multiply move values by 2.</UiItem>
<UiItem name="Left" area="40.0,50.6,1.7,4.3">Decrement move axes preset.</UiItem>
<UiItem name="Right" area="43.5,50.6,1.7,4.3">Increment move axes preset.</UiItem>
</UiList>

**Bumpers**

<UiList label="Bumpers">
<UiItem name="L bumper" area="66.2,9.4,3.6,7.4">Set move axes to low preset.</UiItem>
<UiItem name="R bumper" area="66.2,9.4,3.6,7.4">Set rotate axes to low preset.</UiItem>
</UiList>

**Triggers**

<UiList label="Triggers">
<UiItem name="L trigger" area="63.9,17.1,4.8,9.7">Move Avatar/Camera down.</UiItem>
<UiItem name="R trigger" area="63.9,17.1,4.8,9.7">Move Avatar/Camera up.</UiItem>
</UiList>

**Face Buttons**

<UiList label="Face Buttons">
<UiItem name="A" area="55.1,42.7,2.8,5.8">Divide rotate values by 2.</UiItem>
<UiItem name="B" area="57.5,37.8,2.8,6.0">Increment rotate axes preset.</UiItem>
<UiItem name="X" area="52.7,37.7,2.8,5.8">Decrement rotate axes preset.</UiItem>
<UiItem name="Y" area="55.1,32.9,2.8,5.7">Multiply rotate values by 2.</UiItem>
</UiList>

**Axes values preset**

<UiList label="Axes values preset">
<UiItem name="Presets" area="2.7,81.3,14.7,16.0">Low: Max = 1.5. Medium: Max = 3. High: Max = 5. Max: Max = 10.</UiItem>
</UiList>
