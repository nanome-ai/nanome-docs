# Account Tiers

Each Nanome account has one of four seats. The seat decides where you can work, in the browser at app.nanome.ai or also in a headset, and what you can do there. Everything on this page comes from [nanome.ai/pricing](https://nanome.ai/pricing).

<CardGrid :cols="2">

<Card badge="Web" title="Free Web Seat" meta="Free, with 50 credits" href="https://app.nanome.ai/register" cta="Create an account">

- 3 workspaces and 1 project in the web app
- View-only collaboration with XR users, and Follow only
- The 5 most recent files and the last 7 days of chats

</Card>

<Card badge="Web" title="Full Web Seat" meta="1000 credits a month">

- Projects and workspaces, collaboration with XR users, Spotlight and Follow
- MCP Server calls & Claude Skills
- Unlimited file access and chats

</Card>

<Card badge="Web and XR" title="Collab" meta="50 credits">

- XR visualization and collaboration
- Trajectory and multi-frame playback in XR
- View-only projects and workspaces, and view-only access to others' workspaces

</Card>

<Card badge="Web and XR" title="Full Seat" meta="1000 credits a month">

- Every web and XR feature, including the XR chemical builder and MARA voice commands
- MCP Server calls & Claude Skills
- Unlimited file access and chats

</Card>

</CardGrid>

Every new account gets a 14-day Full license trial, with no credit card required.

## <AppIcon name="receipt" /> Prices {#prices}

As listed on [nanome.ai/pricing](https://nanome.ai/pricing) in October 2026, billed annually:

| Plan | Seat | Price |
| --- | --- | --- |
| Starter | Free Web Seat | Free, with 50 MARA credits |
| Academic: Classroom / Personal | Free Web Seat | Free |
| | Full Seat | $250 a year |
| Academic: Department (minimum 50 licenses) | Full Web Seat | From $50 a year |
| | Full Seat | $150 a year |
| Commercial: Cloud or Enterprise | Full Web Seat, Collab, Full Seat | By quote |

- **Academic: Department** also includes syllabus and course implementation assistance, devices that the Nanome support team or a deployment partner can manage, and shared molecular file storage.
- **Commercial: Cloud** runs on a single-tenant Nanome-hosted stack with premium support. **Commercial: Enterprise** is deployed behind the organization's firewall, on a private cloud or on-premise; its network needs are in [Getting Started](/getting-started#on-prem).
- Customers in Japan contact Nanome's partner, Fujitsu.

For a quote, use **Contact us** on [nanome.ai/pricing](https://nanome.ai/pricing).

## <AppIcon name="list" /> Assigning seats {#assign}

An admin assigns seats at home.nanome.ai under **Licenses** > **Assign Users**, using each user's account email. Step by step: [Manage Licenses](/home.nanome.ai/licenses). [Accounts & licenses](/getting-started#account) in Getting Started covers getting a whole team ready.
