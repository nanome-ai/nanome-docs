# Users & Sharing

The **Users** tab of a workspace controls who can open it and what they can change. It also sends the workspace to colleagues in Nanome XR.

<vimg src="nanome-web/users-tab.jpg" />

## Join via Code

Every workspace has an 8-character code, shown at the top of the tab in the form `XXXX-XXXX`. Anyone with access can type the code into **Join via Code** in Nanome Web, or into the [Workspaces tab](/nanome_v2/mainpanel#workspaces-tab) in Nanome XR. **Copy link** copies a link to the workspace instead.

## Link access

**Link access** sets what happens when someone opens the workspace's code or link:

- **Members only**: only people added to the workspace can open it.
- **Anyone can view**: anyone with the code or link can open it as a Viewer.
- **Anyone can edit**: anyone with the code or link can open it as an Editor.

<vimg src="nanome-web/users-link-access.jpg" />

**Public workspace** (Allow anonymous viewers) lets people open the workspace without signing in.

<Callout type="warning" title="Check sharing before adding unpublished data">

**Anyone can view** together with **Public workspace** makes the workspace readable by anyone who has its code or link, with no sign-in. **Members only** limits a workspace that holds proprietary structures to the people added to it.

</Callout>

## Adding people

The **Workspace** tab under the sharing settings lists the people added to this workspace and their role. **Add people by email** takes an email address, the role menu beside it sets **Viewer** or **Editor**, and **+ Add** invites them. The address has to match their Nanome account exactly.

<vimg src="nanome-web/users-invite-role.jpg" />

The **My Org** tab lists colleagues in your organization.

Roles:

- **Owner**: the workspace's owner.
- **Editor**: can change the workspace.
- **Viewer**: can open the workspace and look around without changing it.

## Sending a workspace to a headset

**Open in XR**, in the workspace header, sends the workspace to Nanome XR on your headset. Nanome XR shows a **Load from Web** prompt that asks whether to load it **Just Me** or **Load for All**, which brings everyone in your current session along. **Queue for All**, at the bottom of the Users tab, also queues the workspace for Nanome XR.

## Following from the web

Nanome Web can follow someone in Nanome XR, so the browser view tracks what they're looking at. Since release 2.7, following also shows the leader's current tool, what they hover and select, and their edits as they make them. Following someone who is following another person leads to the person at the end of the chain. Web viewers start following straight away, without the earlier 6-second delay.
