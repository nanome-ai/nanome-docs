## <AppIcon name="server" /> Private, secure collaboration server {#collaboration-server}

Recommended specs:

- 1 quad core CPU (e.g., Intel Xeon 3440, E3-1230 etc.)
- 4 GB RAM
- 1 GBps NIC / uplink port speed
- Windows Server 2012 and above
